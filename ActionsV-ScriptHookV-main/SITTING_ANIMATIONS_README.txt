ActionsV - Sitting Animations source modification
=================================================

Changes:
- Added a "Sitting Animations" entry to the main ActionsV menu.
- Added standalone menu actions for chair, bench, wall, steps, ledge, picnic-style sitting, and slumped/stupor sitting scenarios.
- Added "Stand Up / Stop" to clear the player's current task.
- Existing source files and the original prebuilt ActionsV.asi are retained in this source archive.

Important:
- This archive contains MODIFIED SOURCE CODE, not a newly compiled ActionsV.asi.
- The source project targets Visual Studio C++ toolset v143, x64, and links against ScriptHookV.lib.
- Build and in-game testing are still required. Scenario availability and exact sit poses can vary by GTA V build and player position.
- Back up the original ActionsV.asi before replacing anything. Do not copy the old bin/Release/ActionsV.asi expecting it to contain these changes.
